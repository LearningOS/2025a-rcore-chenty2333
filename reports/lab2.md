# 实现功能

1. 通过`get_time_us()`获取系统时间, 放入`TimeVal`结构体中, 通过`core::slice::from_raw_parts`获取bytes, 写入通过`translated_byte_buffer`从`ts`虚拟地址获得的`Vec`.
2. 改写`os/src/task/task.rs`, 统计每个`syscall`被调用的次数
3. 改写`sys_strace`, 模仿`translated_byte_buffer`函数, 增加`translate_one`闭包函数, 验证虚拟地址的`U`位, 是否可访问.
4. 增加`sys_mmap`函数, 首先验证`start`和`len`参数是都合法, 在`TaskManager`中增加`insert_framed_area_current`函数, 先检查和已分配的区域是否重合, 再调用`MemorySet`中的`insert_framed_area`函数分配内存.



# 简答作业

1. `bit0`表示`Valid`, `bit 10-53`为`PPN`, `1-3`为`RWX`, `4`为`U`, `5`为`Global`, `6-9`非零触发`page fault`, `60`为`Accessed`标识是否访问, `61`标注是否`Dirty`.
2. 1. 访问到未分配的地址; 访问到已经分配的但是没有对应`ppn`的页; 权限不够.
   2. 用的时候再分配, 不用花多余时间在分配用不到的内存页上面.
   3. 10GB大概需要20MB.
   4. 把页表里对应的`ppn`改成`trap_handler`的地址?
   5. `pte`里的标示位`bit0`为0, 表示页面swapped out.
3. 1. 修改`satp`寄存器中的页表基址.
   2. 通过`pte`中的`U`位.
   3. 单页表不用在每次进入`S`态时候切换页表, 所以开销小.
   4. 双页表每次进入退出`S`态和切换`task`的时候会更换页表. 我写一个单页表操作系统, 只会在`task`切换时需修改`satp`.
